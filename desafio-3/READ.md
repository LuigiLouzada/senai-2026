# Desafio 03 - Fila de Atendimento

Projeto desenvolvido em Java para praticar estruturas de fila e organização de dados.

## Conceitos trabalhados

Fila
FIFO
Listas

## Tecnologia utilizada

Java

## Funcionalidades

Entrada de pacientes na fila
Atendimento por ordem de chegada
Remoção de pacientes atendidos
Organização da fila de atendimento
